# Research: In-Memory Python Console Todo Application

## Research Approach
A research-concurrent approach will be used. No deep, upfront research is required as the project is constrained to the Python standard library.

## Key Areas for On-the-Fly Validation
- **Console I/O**: Best practices for using Python's built-in `input()` and `print()` functions for a clean user experience.
- **Data Structures**: Standard usage of Python `lists` and `dictionaries` for in-memory state management.
- **Control Flow**: Standard patterns for a main application loop (`while True`) and handling user menu selections (`if/elif/else`).
- **Input Validation**: Techniques for validating and casting user input, particularly handling non-integer input when an integer is expected.
