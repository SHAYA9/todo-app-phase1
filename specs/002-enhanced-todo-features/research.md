# Research: In-Memory Python Console Todo Application (Intermediate Level)

## Research Approach
A research-concurrent approach will be used, building upon the Phase-1 research. The focus will be on efficiently implementing the new features using Python's standard library.

## Key Areas for On-the-Fly Validation
- **Console I/O**: Efficiently handle multiple inputs for priority and tags.
- **Data Structures**: Confirm that adding priority and tags to the existing list of dictionaries is straightforward and efficient.
- **Search/Filter Logic**: Best practices for implementing keyword search and filtering by multiple criteria (status, priority, tags) using Python's built-in functions.
- **Sorting Logic**: Confirm stable sorting by multiple keys (priority, title) using Python's `sorted()` function with custom `key` functions.
- **Input Validation**: Robust validation for new inputs like priority values ("High", "Medium", "Low") and parsing multiple tags (e.g., comma-separated).
