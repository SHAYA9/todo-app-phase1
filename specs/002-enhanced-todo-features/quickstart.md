# Quickstart: In-Memory Python Console Todo Application (Intermediate Level)

## Prerequisites
- Python 3.x

## Running the Application
1.  Navigate to the `src` directory.
2.  Run the application using the following command:
    ```bash
    python main.py
    ```
3.  The application will start and display the main menu. Follow the on-screen prompts to manage your tasks, including new features for priority, tags, search, filter, and sort.
